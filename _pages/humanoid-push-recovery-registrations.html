Registrations

Every comparison in the paper was registered before its runs (offline comparisons: before the analysis). For each test below: the registration (CRITERIA_*.json, including all amendments), its sha256 file, and the result summary written by the registered analysis. For the hardware tests, the sha256 file also covers the analysis scripts and configurations; they are given here in their hashed versions (the paths in the sha256 files refer to the project repository; each file's hash matches). Registration times are those stated in each file; commit times of the project repository are not an independent timestamp.
