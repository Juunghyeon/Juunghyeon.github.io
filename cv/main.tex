\section{Research Experience}

\researchentry{Balance-Aware Whole-Body Control for Humanoid Standing Manipulation}{Mar. 2025 -- Present}
\detail{Formulated a \textbf{Balance Demand Descriptor (BDD)} based on centroidal dynamics to represent balance demands induced by upper-body motion, payloads, and external interaction. Integrated BDD into a reinforcement-learning locomotion policy to distinguish demands manageable within the current stance from those requiring corrective stepping.}

\researchentry{Visual Perception for Quadrupedal Object Interaction}{Mar. 2025 -- Nov. 2025}
\detail{Developed a dual-camera perception system to track a ball and moving ArUco markers from fixed global and onboard views. Calibrated the cameras and transformed observations into a common coordinate frame to maintain target localization during robot motion and partial occlusion.}

\detail{Developed a ROS~2 communication architecture connecting simulation, an LLM, a user interface, and a physical mobile manipulator. Implemented edge-based robot data collection with automatic cloud synchronization while preserving the robot's real-time control cycle.}
